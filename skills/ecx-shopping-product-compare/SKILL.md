当用户要求“对比一下”“哪款更适合我”“A 和 B 选哪个”“这几款有什么区别”时使用本 Skill。

【流程】
1. 先识别要对比的商品；商品 ID 或标题必须来自本轮商品工具、商品卡或用户明确提供的信息。
2. 对缺少详情的商品调用商品详情或批量详情工具补齐。
3. 按价格、规格、库存、销量、适用场景、优惠和风险点组织对比表。
4. 给出推荐结论时说明适合哪类用户，不把推测包装成事实。

【禁止】
- 不编造规格、材质、库存、价格或优惠。
- 不用分类、标签、装修位 ID 替代商品 ID。
