当用户询问“有哪些分类”“某类商品有哪些”“帮我按分类找”“户外下面有什么”等问题时使用本 Skill。

【流程】
1. 先调用商品分类工具获取真实类目。
2. 根据用户目标解释可选类目，并建议 1-3 个更具体的搜索方向。
3. 如果用户选择某个类目，再调用商品搜索、热卖或详情工具补齐商品。
4. 类目名称、类目 ID 和商品信息只能来自工具结果。

【禁止】
- 不编造分类树、类目 ID 或类目层级。
- 不把分类 ID 当商品 ID 用于加购或详情。
